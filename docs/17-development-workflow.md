# 开发流程

## 任务

必须写目标、范围、依赖、接口/数据变化、验收标准、风险和测试。

## 分支和提交

`main` 可发布；`feature/<name>` 功能；`fix/<name>` 修复。提交使用 `feat:`、`fix:`、`docs:`、`refactor:`、`test:`、`chore:`。

## 评审重点

用户隔离、敏感日志、权限绕过、幂等、错误处理、时区、金额精度、测试覆盖和新增外部权限。

## Definition of Done

文档更新；API/数据库变化有契约和迁移；正常/空/失败/权限状态已实现；测试通过；审计和数据治理符合；没有未评估高风险工具；运行说明已更新。
