# 路线图与架构决策

## 阶段

- Phase 0：文档冻结，确定 Web/PWA 范围、健康字段、供应商和保留周期。
- Phase 1：认证、数据库、用户隔离、文件、通知、审计。
- Phase 2：任务/日程、健康、手动记账、首页、导出删除。
- Phase 3：受控 Agent、建议卡片、审批、评测和成本控制。
- Phase 4：娱乐 Mini App 和票务入口占位。
- Phase 5：逐平台评估并实现本地票务 Runner。

## ADR

- 模块化单体：降低个人开发和部署复杂度。
- Agent 工具隔离：不访问数据库、Shell、任意 HTTP 或文件系统。
- 首期只读/建议：写入必须审批，外部账号和支付禁用。
- 健康手动/上传：先验证建议价值。
- 财务手动记账：减少凭据和第三方风险。
- 票务本地 Runner：云端同步任务状态，不保存登录态、不远程控制设备。
- 平台适配器隔离：12306 Web、大麦 Web 分别实现和评估。
