# 测试规范

## 层级

单元：领域规则、解析、金额、状态机、Policy；集成：API、数据库、队列、对象存储；合约：API 与 contracts；E2E：Web 与手机浏览器核心流程；Agent 评测；票务只用模拟页面/测试环境。

## P0 用例

用户隔离、登录/退出、任务和提醒幂等、健康解析/错误行/重复导入、金额精度和月份、Agent 越权/Prompt Injection/无数据、审批生命周期、导出删除。

## 安全回归

伪造 `userId`、越权资源 ID、伪造审批、恶意文件、日志泄露凭据、Agent 要求 Shell/任意 HTTP/支付。

## 发布门槛

类型检查、单元/集成测试、依赖检查、迁移临时库验证、关键 E2E、监控备份回滚步骤全部通过。
