## 当前阶段

当前阶段是 **文档设定和架构冻结**，不是功能开发阶段。

- 已有代码仅作为架构验证骨架，不代表 MVP 已完成。
- 暂不增加真实数据库、登录、模型、第三方账号或抢票功能。
- 后续开始开发时，按路线图的 Phase 0 逐项完成基础准备。

## 文档变更规则

- 产品范围、权限、安全和数据模型发生变化时，先更新文档，再修改代码。
- 新增 Agent 工具必须同时更新 Agent 工具目录、权限等级和审计要求。
- 新增敏感数据必须更新数据分级、保存期限和删除策略。
- 重大架构选择记录在决策记录中，不依赖聊天记录作为唯一依据。
- 文档版本使用 `V主版本.次版本`：范围变化升主版本，澄清和补充升次版本。
