# 用户流程

## 首次使用

登录 -> 设置时区和通知 -> 可选填写健康偏好 -> 首页。通知拒绝不阻塞使用，健康偏好可跳过。

## 待办

首页/任务 -> 新建 -> 标题、截止时间、提醒 -> 校验 -> 保存 -> 创建提醒任务。自然语言只生成草稿，用户确认后保存。

## 健康上传

选择文件 -> 类型/大小检查 -> 解析 -> 字段映射 -> 预览错误行 -> 用户确认 -> 幂等写入 -> 导入报告。取消或失败不写正式表。

## 手动记账

新建消费 -> 金额/日期/分类校验 -> 保存 -> 更新月度聚合 -> 首页刷新。编辑/删除审计。

## Agent

输入 -> 意图识别 -> 最小上下文 -> 白名单工具 -> Policy -> 结构化输出 -> 建议卡片或审批。无数据时明确说明，不编造。

## 票务

配置平台和条件 -> 用户主动启动 -> 本地 Runner 读取可见页面 -> 筛选和跳转 -> 验证码/订单/支付前暂停并由用户接管。
