# 安全与数据治理

## 分级

L0：公共 Mini App 配置；L1：任务、日程和普通设置；L2：健康、饮食偏好、消费和对话摘要；L3：密码、Token、支付密钥和第三方凭据，首期不保存。

## 生命周期

业务记录保留到用户删除；对话原文、Agent 原始输入和上传原文件按配置周期清理；审计只保留追踪所需摘要；加密备份按保留周期过期。

## 基础安全

HTTPS、HttpOnly Cookie、Secret Manager、查询强制当前用户过滤、L2 脱敏日志、必要时应用层加密、私有对象存储短期 URL、限流、超时、重试上限和成本配额。

## 用户能力

查看、导出、删除记录；清空对话和记忆；撤销设备和外部授权；删除账户。

## 审计和响应

审计登录、设备撤销、导入、Agent 工具、审批、导出/删除、Runner 注册/停止和连接器授权。泄露事件先撤销会话/授权、禁用工具、保留证据、评估范围、轮换密钥、修复和回归。
