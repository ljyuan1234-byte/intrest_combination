# 健康模块

## 首期指标

`steps/count`、`sleep/min`、`water/ml`、`weight/kg`、`exercise/min`、`diet_note/text`。

## 校验

数字为有限非负数；超出合理范围要求确认；日期为用户本地日期；单位不匹配拒绝导入；同一用户、日期、指标、来源批次做重复检测。

## 上传

首期 CSV/JSON：文件检查 -> 解析 -> 预览 -> 用户确认。原文件和模板不作为执行代码。后续在 `docs/examples/` 添加模板。

## 建议

可选档案：身高、体重、年龄、目标、过敏源、忌口、饮食偏好、运动限制和可用时间。建议包含行动、依据时间范围、限制、非医疗说明和生成时间。禁止诊断、处方、停药和紧急判断。
