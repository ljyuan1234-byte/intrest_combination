# 产品需求与范围

## P0

登录、个人设置、今日首页、待办、内部日程、提醒、健康手动记录/文件导入、饮食和锻炼建议、手动记账、分类统计、Agent 只读查询、Android/Web 推送、数据导出删除和审计。

## P1

ICS 日程导入、健康趋势、预算、用户主动记忆、娱乐/传统文化 Mini App、票务偏好和任务占位。

## P2

12306 和大麦 Web/Android 本地页面辅助 Runner、官方授权连接器、家庭共享、审核签名沙箱插件。

## 非目标

不做医疗诊断、投资/支付/转账、不依赖微信、不自动采集健康数据、不保存第三方密码或浏览器凭据、不在云端远程控制设备、不绕过验证码/风控/登录保护、不允许 Agent 任意执行 Shell、HTTP、文件或支付。

## 验收标准

- 首次登录后 3 分钟内可创建待办和消费。
- 健康上传必须预览确认，失败不产生半条记录。
- Android/Web 使用同一 API 契约且数据一致。
- Agent 仅调用白名单工具，建议显示数据范围和免责声明。
- 用户可以导出和删除个人数据。
